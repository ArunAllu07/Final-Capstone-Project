💰 Price Prediction using Machine Learning (XGBoost)

This repository contains my Final Capstone Project for the Machine Learning program at IIT Guwahati (Jun’25 – Jul’25).

The main objective was to understand how different features influence prices and to build a machine learning model that could predict prices accurately. I started with an extensive Exploratory Data Analysis (EDA) to uncover patterns and relationships in the dataset. Based on those insights, I developed and tuned several models, with XGBoost giving the best results.

By the end of the project, I was able to improve prediction accuracy from 0.88 to 0.97, which translates to around a 10% improvement in performance.

🔎 What I Did

Performed EDA to find correlations and patterns in the dataset

Built and compared multiple ML models for prediction

Applied XGBoost (Gradient Boosting) as the final model

Optimized hyperparameters for the best performance

Improved predictions by ~10% and achieved 97% accuracy
